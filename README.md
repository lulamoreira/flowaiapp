# FlowAI

Crie um aplicativo exatamente igual ao Monday (visualmente também).  Adicione componentes de gráficos (usando Recharts ou similar) na página de detalhes do board para visualizar o progresso de conclusão das tarefas por grupo, além de um gráfico de pizza para mostrar a distribuição de prioridades.  Melhore a visualização das tarefas, adicionando a possibilidade de ver detalhes das tarefas em um modal ao clicar nelas, incluindo campos para descrição, subtarefas e anexos.
